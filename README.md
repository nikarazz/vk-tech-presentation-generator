# vk-tech-presentation-generator

Сервис генерации презентаций по шаблону

## Что делает

1. Парсит шаблон .pptx → извлекает дизайн-систему.
2. Генерирует структуру и контент презентации по брифу.
3. Раскладывает слайды по шаблону.
4. Аудит и исправление артефактов.
5. Экспорт в .pptx, .pdf, .html.
