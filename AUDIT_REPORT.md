# Отчёт об аудите проекта

## 1. Общие сведения

| Параметр | Значение |
|---|---|
| Проект | vk-tech-presentation-generator |
| Модуль | `audit/` |
| Цель | Проверить состояние модуля аудита на соответствие ТЗ |

## 2. Методика

Проведён аудит модуля `audit/`:
- проверено наличие файлов;
- проверено содержимое каждого файла;
- проверено соответствие требованиям ТЗ;
- составлен список проблем и задач.

## 4. Соответствие ТЗ

| Требование ТЗ | Статус | Комментарий |
|---|---|---|
| Аудит сгенерированной презентации | есть | Детерминированные проверки |
| Подсветка проблемных участков | есть | Через `bbox` в `Issue` |
| Исправление проблем (repair) | базовое | Сдвиг, шрифт, цвет |
| Детерминированные проверки | есть | 6 проверок |
| Контекстный аудит (VLM) | заготовка | Требуется API и модель |
| Экспорт редактируемого .pptx | требует проверки | Вне модуля аудита |
| Экспорт редактируемого .html | требует проверки | Вне модуля аудита |
| Встраивание в pipeline | не сделано | Следующий шаг |
| Вывод проблем в UI | не сделано | Следующий шаг |
| Тесты | базовые | 4 теста |

## 5. Найденные проблемы

1. Полноценный рендер слайдов в изображение не реализован (только заготовка `render.py`).
2. VLM-аудит не подключён: нет API-клиента и модели.
3. Аудит не встроен в `pipeline/run.py`.
4. Подсветка проблемных участков в UI не реализована.
5. Расширенные тесты отсутствуют (только базовые).
6. `_fix_density` в `repair.py` — заглушка (не разбивает слайды).

## 6. Что нужно доделать

1. **Рендер слайдов** — реализовать через LibreOffice.
2. **VLM-аудит** — подключить модель ≤ 35M параметров.
3. **Интеграция в pipeline**.
4. **UI** — вывести список проблем и подсветить `bbox`.
5. **Тесты** — расширить на `overlap`, `typography`, `colors`, `density`.
6. **Проверка экспорта** — убедиться, что `.pptx` и `.html` редактируемые.

## 7. Выводы

Модуль аудита реализован на базовом уровне:
- детерминированные проверки работают;
- `repair` выполняет базовые исправления;
- тесты покрывают основные сценарии;
- модели данных описаны;
- VLM-аудит — заготовка;
- интеграция в pipeline и UI — следующие шаги.

## 8. Рекомендации

1. Интегрировать аудит в `pipeline/run.py`.
2. Вывести проблемы в UI с подсветкой по `bbox`.
3. Подключить VLM для контекстного аудита.
4. Расширить тесты.
5. Проверить редактируемость экспорта `.pptx` и `.html`.
